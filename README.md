# Etupa Dalamud Plugins

A consolidated repository for all my Dalamud plugins.

## Plugins Included
- **EmoteGrid**: Scalable ImGui grid for emotes.
- **Nameplate Toggle**: Quick toggle for nameplate presets.

## Installation
Add the following URL to your Dalamud Plugin Repositories:
`https://raw.githubusercontent.com/Etupa/Dalamud_Plugins/master/pluginmaster.json`
